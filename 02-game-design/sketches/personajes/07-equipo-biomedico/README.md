# Equipo biomédico

- **Rol:** prepara el acceso vascular en el antebrazo del paciente y monitorea sus constantes.
- **Altura:** 1.70 m. Pijama quirúrgico, bata, guantes, gafas de protección y cubrebocas.
- **Pendiente antes de modelar:** cubrebocas en todo el personal que punciona; bata clínica o quirúrgica estéril; "acceso venoso" y no "puerto".

# Game Design
Sketches, storyboards y el cartel para la feria de ciencias.

- `sketches/` — `minijuego-<nombre>_<tema>_v1.png`
- `storyboards/` — una carpeta por minijuego
- `cartel-feria/` — fuentes editables y versión final para imprimir

# Investigación
Entender las estructuras biológicas y comunicarlas de forma que sea realizable una visualización.

- `fichas/` — una ficha por estructura, copiando `fichas/_plantilla.md`. Nombre: `atp-sintasa.md`
- `referencias/` — bibliografía (`referencias.bib`) y material de apoyo

Las fichas alimentan a Game Design, Diseño y al pokédex del juego, así que respeta los campos de la plantilla.
